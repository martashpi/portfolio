# Аудит стилей сайта

Дата аудита: 15 октября 2026 года.

## 1. Короткий итог

В проекте есть один общий CSS-файл — `css/styles.css`. Его подключают главная страница, резюме и все опубликованные страницы проектов. Внутри этого файла находятся сразу три разных слоя:

1. общие правила для всего сайта;
2. оформление главной страницы и обычных внутренних страниц;
3. большие отдельные блоки для конкретных проектов.

Кроме него есть два тестовых HTML-файла со своими встроенными стилями:

- `book-model-preview.html` — тестовая страница 3D-книги;
- `flyer-model-preview.html` — тестовая страница 3D-листовок.

Атрибутов вида `style="..."` в HTML нет. То есть оформление не спрятано внутри отдельных тегов. Однако JavaScript программно меняет несколько CSS-переменных, классов и свойство `transform`, а также рисует 3D-сцены на `<canvas>`.

CSS-анимаций через `@keyframes` нет. Движение возникает за счёт:

- `transition` в CSS;
- состояний `:hover`, `:active` и `:focus-visible`;
- классов `.is-ready`, `.has-error`, `.has-interacted`, `.is-second`;
- JavaScript и `requestAnimationFrame` для 3D-моделей.

## 2. Как HTML, CSS и JavaScript работают вместе

Простая схема:

```text
HTML задаёт элементы и их классы
        ↓
css/styles.css находит эти классы и оформляет элементы
        ↓
JavaScript иногда меняет класс, CSS-переменную или transform
        ↓
CSS реагирует на новое состояние, либо JavaScript перерисовывает canvas
```

Например, на странице книги HTML создаёт контейнер `.orange-book-viewer`. CSS задаёт его размер, курсор и поведение запасной картинки. JavaScript вставляет внутрь `<canvas>`, рисует на нём книгу и добавляет класс `.is-ready`. После этого правило `.orange-book-viewer.is-ready .orange-book-viewer__fallback` плавно скрывает запасную картинку.

Параметры `?v=20261015-20` в адресах CSS и JavaScript не обозначают другие файлы. Это версии для очистки браузерного кеша: браузер видит новый адрес и загружает свежую копию того же файла.

## 3. Все источники стилей

### 3.1. `css/styles.css`

Главный и единственный отдельный CSS-файл проекта, 1184 строки.

Он содержит:

- подключение шрифта Inter из Google Fonts;
- базовые правила для `body`, ссылок, картинок и заголовков;
- всю главную страницу;
- общий шаблон простых внутренних страниц;
- отдельное оформление резюме;
- отдельные макеты Moo Moo, интерьерных проектов, ширм, дверей, знака, «Заводного апельсина» и персональной выставки;
- оформление 3D-книги и 3D-листовок;
- временный режим инспектора стилей.

### 3.2. Встроенный `<style>` в `book-model-preview.html`

Этот блок действует только на тестовую страницу 3D-книги. Общий `css/styles.css` туда не подключён.

Он оформляет:

- серо-бежевый фон страницы;
- заголовок и пояснение;
- белую область `.book-prototype` с 3D-книгой;
- подсказку «Потяните, чтобы повернуть книгу»;
- панель `.book-editor` с ползунками;
- мобильный вариант при ширине до 700 px.

### 3.3. Встроенный `<style>` в `flyer-model-preview.html`

Этот блок действует только на тестовую страницу 3D-листовок. Общий CSS туда тоже не подключён.

Он оформляет:

- серый фон страницы;
- сетку из двух карточек предпросмотра;
- квадратные области `.flyer-3d-viewer`;
- текст загрузки до появления canvas;
- редактор положения двух листовок;
- мобильный вариант при ширине до 700 px.

### 3.4. Встроенные и программные стили

В HTML нет ни одного атрибута `style="..."`.

Но JavaScript меняет внешний вид через DOM API:

- `index.html` записывает CSS-переменные `--shift-x`, `--shift-y` и `--posters-height`;
- `js/personal-exhibition.js` записывает картинке `transform: translateX(...)`;
- `js/orange-book-prototype.js` задаёт фильтр насыщенности canvas;
- Three.js создаёт WebGL-canvas и рисует материалы, свет, тени и текстуры;
- тестовые редакторы передают визуальные настройки в JavaScript.

Это важно: часть внешнего вида 3D-объектов находится не в CSS, а в параметрах света и материалов внутри JavaScript.

## 5. Глобальные стили

Глобальными называются правила, которые могут влиять сразу на много страниц.

### Шрифт

Первая строка `css/styles.css` загружает Inter с начертаниями 400, 500, 600, 700 и 800. Основной стек:

```css
Inter, Arial, sans-serif
```

Если Google Fonts недоступен, браузер использует Arial, а затем любой доступный шрифт без засечек.

### Базовые правила

- `* { box-sizing: border-box; }` — указанная ширина включает внутренние отступы и рамку. Это делает расчёты размеров предсказуемее.
- `html { scroll-behavior: smooth; }` — переход к якорю страницы прокручивается плавно.
- `body` — убирает стандартный внешний отступ, задаёт белый фон, цвет, шрифт и межстрочное расстояние.
- `a` — ссылки наследуют цвет и не имеют подчёркивания по умолчанию.
- `img` — картинки становятся блочными и занимают всю доступную ширину.
- `h2, h3, p` — стандартные отступы браузера обнуляются.

### Глобальный hover ссылок

Правило

```css
a:hover h2,
a:hover .site-name,
a:hover.resume-link
```

подчёркивает заголовок карточки, имя в шапке или ссылку на резюме при наведении мыши.

### Общие внутренние страницы

Правила `body:not(.portfolio-page)` применяются ко всем страницам, кроме главной. Их явно используют:

- `template.html`;
- `cv/index.html`;
- `projects/3-books/index.html`;
- `projects/tangiers-lounge-logo/index.html`;
- `projects/doors/illustrations.html`.

Формально эти правила также совпадают со специализированными страницами Moo Moo, дверей, знака, ширм, книги и выставки. Там большая часть параметров переопределяется более точными селекторами. Это скрытая связь: изменение общего правила для `body:not(.portfolio-page)` потенциально может затронуть и специальные страницы.

## 6. CSS-переменные

CSS-переменная — это именованное значение. Его можно определить один раз, а затем использовать через `var(...)`.

### Глобальные переменные в `:root`

| Переменная | Значение | Назначение |
|---|---:|---|
| `--ink` | `#141414` | основной почти чёрный цвет текста |
| `--muted` | `#676767` | приглушённый серый текст |
| `--content` | `980px`, затем `900px` от 700 px | предельная ширина главной страницы |
| `--tile-gap` | `clamp(10px, 2.5vw, 20px)` | адаптивный промежуток между карточками |
| `--segment-gap` | `clamp(2px, .5vw, 4px)` | маленький промежуток между частями коллажа |
| `--poster-column-width` | `clamp(100px, 27vw, 190px)` | ширина колонки проекта 365+ Posters |

`clamp(минимум, желаемое, максимум)` позволяет размеру плавно зависеть от ширины экрана, но не выходить за заданные границы.

### Локальные и динамические переменные

| Переменная | Где используется | Кто задаёт |
|---|---|---|
| `--shift-x`, `--shift-y` | движение изображений книг и визуальной системы | CSS задаёт ноль, JavaScript меняет при движении указателя |
| `--base-x` | исходное горизонтальное положение трёх изображений `.visual-scene` | CSS для каждого `:nth-child(...)` |
| `--posters-height` | высота прокручиваемой колонки постеров | JavaScript синхронизирует её с соседней колонкой |
| `--art-x`, `--art-y` | точная подстройка картинок карточек дверей, знака и ширм | CSS, отдельно для desktop и mobile |

Других CSS-переменных в проекте нет.

## 8. Подробно о стилях главной страницы

Главную отличает класс `<body class="portfolio-page">`. Благодаря ему она не получает правила обычных внутренних страниц.

### Шапка

- `.site-header` ограничивает ширину и раскладывает имя с навигацией по разным краям.
- `.site-header__identity` ставит имя и резюме друг под другом.
- `.is-current` выделяет текущий раздел более тёмным и плотным текстом.

### Основная сетка

- `.portfolio` задаёт общую ширину и вертикальные отступы.
- `.intro-grid` создаёт две колонки первых проектов.
- `.doors-layout` создаёт узкую колонку постеров и широкую колонку интерьерного проекта.
- `.identity-grid` создаёт маленькую колонку видео и большую визуальную композицию.
- `.media-grid` делит медиапроекты на две колонки.

### Коллажи с движением

`.books-showcase` и `.visual-showcase` скрывают выступающие части увеличенных изображений. При `:hover` масштаб меняется с `1.02` на `1.08`. Встроенный скрипт в `index.html` дополнительно двигает изображение вслед за курсором через `--shift-x` и `--shift-y`.

### Колонка постеров

`.posters-scroll` имеет собственную вертикальную прокрутку и скрытый scrollbar. Псевдоэлементы `::before` и `::after` создают белые размытые маски сверху и снизу. Высота `.posters-card` берётся из `--posters-height`, которую JavaScript вычисляет по высоте соседней `.doors-column`.

### Видео

JavaScript начинает загрузку `.identity-video` только незадолго до появления элемента на экране. Это не меняет CSS, но влияет на момент появления движущегося изображения.

## 9. Обычные внутренние страницы

Они построены в нормальном вертикальном потоке: элементы идут сверху вниз и сами раздвигают страницу.

Общий шаблон задаёт:

- максимальную ширину 860 px;
- боковые отступы `1.5rem`;
- крупный адаптивный `h1` через `clamp(...)`;
- текст не шире 62 символов (`62ch`), чтобы строки было легче читать;
- стандартные отступы фигур и подвала.

Это наиболее гибкая часть сайта: она меньше зависит от точных координат.

### CV

`#cv-page .cv-grid` создаёт две колонки. При ширине до 520 px они превращаются в одну колонку. Email специально окрашен в синий и подчёркнут.

## 10. Специализированные проектные страницы

### Общий принцип фиксированных сцен

Moo Moo, «Двери», «Знак», «Заводной апельсин» и персональная выставка построены похожим способом:

1. `<main>` имеет фиксированную ширину 1400 px и большую фиксированную высоту.
2. Тексты и картинки имеют `position: absolute`.
3. Для каждого элемента вручную записаны `top`, `left`, `width` и `height`.
4. Между 900 и 1399 px вся сцена уменьшается целиком через `transform: scale(...)`.
5. До 899 px включается отдельная мобильная композиция с новыми координатами.

Плюс такого подхода — очень точное совпадение с макетом. Минус — почти любое изменение текста или размера картинки может потребовать вручную передвинуть все элементы ниже.

### Moo Moo

- Desktop-сцена: 1400 × 6500 px.
- Mobile-сцена: ширина до 390 px, высота 3310 px.
- `.moomoo-copy-desktop` и `.moomoo-copy-mobile` меняют варианты текста на мобильной ширине.
- Картинки растягиваются в заданные рамки через `object-fit: fill`.

### Выбор интерьерных проектов

- На desktop три карточки в сетке.
- До 699 px карточки идут вертикально.
- `--art-x` и `--art-y` подправляют положение иллюстраций.
- При наведении название карточки подчёркивается.

### Ширмы

- Максимальная рабочая ширина контента — 1170 px.
- Для восьми медиаблоков заданы свои размеры и интервалы.
- `.screens-media--6` показывает горизонтальный курсор и получает видимую рамку при клавиатурном фокусе.
- `js/screens-scrub.js` меняет `src` картинки в зависимости от положения указателя или стрелок клавиатуры.

### Двери

- Desktop-сцена: 1400 × 17980 px.
- Mobile-сцена: ширина до 390 px, высота 10220 px.
- Это самый длинный фиксированный макет в CSS.

### Знак

- Desktop-сцена: 1400 × 7000 px.
- Mobile-сцена: ширина до 390 px, высота 2000 px.

### Заводной апельсин

- Desktop-сцена: 1400 × 18880 px.
- Mobile-сцена: ширина до 390 px, высота 6330 px.
- `.orange-book-viewer` оформляет интерактивную область книги.
- Запасная картинка лежит под canvas и исчезает за 180 ms после класса `.is-ready`.
- При ошибке WebGL класс `.has-error` скрывает canvas, оставляя запасную картинку.

### Персональная выставка

- Desktop-сцена: 1400 × 16382 px.
- Mobile-сцена: ширина до 390 px, высота 6320 px.
- Использует собственные изображения, две 3D-книги и два вида 3D-листовок.
- `.personal-exhibition-switcher__track` содержит две картинки рядом и сдвигается на 50% при классе `.is-second`.
- `.personal-exhibition-piece--26` — горизонтально перетаскиваемая длинная картинка.
- На mobile декоративный контейнер `.personal-exhibition-piece--stuff` скрывается.

## 11. Адаптивные стили

`@media` — это условие: правила внутри применяются только при определённой ширине экрана или настройке пользователя.

### Общие точки переключения

| Условие | Что меняется |
|---|---|
| `min-width: 700px` | главная получает более широкие отступы, увеличенные промежутки и крупную визуальную композицию |
| `max-width: 699px` | главная сжимает боковые поля и интервалы |
| `max-width: 370px` | уменьшаются заголовки карточек на очень узких телефонах |
| `max-width: 520px` | шапка обычных внутренних страниц и CV становятся одноколоночными |
| `prefers-reduced-motion: reduce` | отключаются CSS-переходы увеличения картинок на главной |

### Специализированные страницы

| Условие | Страницы | Поведение |
|---|---|---|
| `900px–1399px` | Moo Moo, двери, знак, книга, выставка | desktop-сцена 1400 px пропорционально уменьшается целиком |
| `max-width: 899px` | те же страницы | включается отдельно размеченная мобильная сцена |
| `max-width: 699px` | выбор дверных проектов и ширмы | меняются колонки, размеры, поля и интервалы |
| `max-width: 700px` | обе тестовые preview-страницы | сетки становятся одноколоночными |

В 3D-скриптах есть дополнительная программная точка 640 px: при меньшей ширине меняется расстояние камеры и ограничивается плотность рендера canvas. Это не CSS-медиазапрос, но визуально работает похожим образом.

## 12. Hover, focus, active и другие состояния

### `:hover` — указатель находится над элементом

- подчёркиваются заголовки ссылок, имя и ссылка на резюме;
- изображения `.books-showcase` и `.visual-showcase` увеличиваются;
- подчёркиваются названия карточек интерьерных проектов;
- подчёркивается ссылка «О книге здесь».

### `:active` — пользователь нажимает на элемент

У 3D-книги и 3D-листовки курсор меняется с ладони `grab` на сжатую ладонь `grabbing`.

### `:focus-visible` — элемент выбран с клавиатуры

Видимая рамка есть у:

- 3D-книги;
- 3D-листовки;
- интерактивной смены кадров на странице ширм;
- областей в обеих preview-страницах.

Отдельного глобального оформления клавиатурного фокуса для обычных ссылок нет. Браузер использует своё стандартное оформление.

### Классы состояния

| Класс | Кто добавляет | Визуальный результат |
|---|---|---|
| `.is-current` | записан в HTML | выделяет текущий раздел навигации |
| `.is-ready` | 3D-скрипты | скрывает запасную картинку книги; в preview листовки убирает текст загрузки |
| `.has-error` | 3D-скрипты | скрывает неисправный canvas книги |
| `.has-interacted` | 3D-скрипты | в preview книги скрывает подсказку |
| `.is-second` | `js/personal-exhibition.js` | показывает вторую картинку переключателя |
| `.style-inspection` | `js/style-inspector.js` | включает цветные диагностические рамки и подписи |

## 13. Переходы и анимация

### CSS-переходы

- `transform 420ms cubic-bezier(...)` — плавное увеличение и движение коллажей на главной;
- `transform 240ms ease-out` — зарезервированный плавный переход изображений карточек интерьерных проектов;
- `opacity 180ms ease-out` — исчезновение запасной картинки 3D-книги;
- `transform 360ms ease` — переключение двух изображений персональной выставки;
- `opacity 180ms ease` — исчезновение подсказки в preview книги.

### Чего нет

- Нет `@keyframes`.
- Нет свойства `animation`.
- Нет отдельной библиотеки CSS-анимаций.

### Движение из JavaScript

- 3D-книга и листовки вращаются с инерцией через `requestAnimationFrame`.
- При `prefers-reduced-motion: reduce` инерция затухает быстрее, но движение полностью не отключается.
- Переключатели персональной выставки меняются автоматически каждые 5 секунд и вручную свайпом.
- Интерактивная картинка ширм меняет кадр без CSS-перехода.

## 14. JavaScript-файлы, влияющие на внешний вид

### Встроенный скрипт в `index.html`

Отвечает за три визуальных механизма:

1. двигает изображения внутри двух коллажей вслед за указателем;
2. лениво запускает видео;
3. синхронизирует высоту колонки постеров с соседней колонкой.

### `js/style-inspector.js`

Работает только при наличии параметра `styles` в адресе, например:

```text
index.html?styles=1
```

Добавляет диагностический класс и подписи с размером шрифта, высотой строки и толщиной начертания. Это инструмент изучения, а не постоянное оформление.

### `js/screens-scrub.js`

Находит `.screens-scrub` и меняет картинку в зависимости от горизонтального положения указателя. Также поддерживает стрелки влево и вправо.

### `js/personal-exhibition.js`

Управляет двумя видами интерактивных изображений:

- `[data-switcher]` автоматически и по свайпу переключает класс `.is-second`;
- `[data-pan]` напрямую меняет `transform` длинной картинки.

### `js/orange-book-3d.js`

Ищет элементы с `data-component="3D_COMP"`, запускает их только перед появлением на экране и управляет состояниями загрузки, готовности и ошибки.

Также передаёт модели значения яркости, насыщенности, света, матовости, фактуры и начального поворота.

### `js/orange-book-prototype.js`

Это основная реализация вида 3D-книги. Она отвечает за:

- геометрию обложки и страниц;
- текстуры;
- материалы, матовость и фактуру;
- три источника света и тень;
- насыщенность canvas;
- положение камеры для desktop и mobile;
- вращение мышью, пальцем и клавиатурой;
- размер и качество WebGL-canvas.

### `js/flyer-3d.js`

Создаёт 3D-листовки `YOLKA_COMP` и композиции `LISTS_COMP`. Отвечает за материалы бумаги, освещение, тень, камеру, вращение, canvas и классы состояния.

### `js/vendor/three.module.min.js` и `js/vendor/three.core.min.js`

Это минифицированная сторонняя библиотека Three.js. Она предоставляет WebGL-движок, которым пользуются книга и листовки. В ней нет макета страниц сайта, но без неё 3D-внешний вид не создаётся. Редактировать эти файлы как обычные стили проекта не следует.

## 15. Наблюдения о структуре и возможных рисках

Это только результаты анализа; в код ничего не изменялось.

### 1. Один CSS-файл выполняет слишком много ролей

`css/styles.css` одновременно является глобальной базой, стилями главной, стилями обычных страниц и хранилищем пяти больших фиксированных макетов. Изменение в нём требует внимательно проверять весь сайт.

### 2. Общий селектор внутренних страниц слишком широкий

`body:not(.portfolio-page)` совпадает не только с простыми страницами, но и со всеми специализированными проектами. Сейчас более точные правила в основном перекрывают его, однако связь остаётся неочевидной.

### 3. Блок «Заводного апельсина» разорван

Часть правил находится до персональной выставки, часть — после неё. Это не ошибка браузера, но повышает риск изменить не тот участок или не заметить вторую половину.

### 4. Фиксированные страницы чувствительны к содержимому

У длинных проектов вручную заданы высоты страницы и координаты каждого элемента. Если текст станет длиннее, картинка изменит пропорции или добавится новый блок, элементы могут наложиться друг на друга.

### 5. Есть правило, которое больше не соответствует текущему HTML

`.exhibition-project > img` рассчитано на картинку, лежащую непосредственно внутри `.exhibition-project`. Сейчас картинка обёрнута ссылкой, поэтому это конкретное правило не срабатывает. Внешне картинка всё равно получает глобальные `img { display: block; width: 100%; height: auto; }` и `.portfolio-page * { border-radius: 0 !important; }`.

### 6. Доступность движения учтена частично

Настройка `prefers-reduced-motion` отключает переходы на главной и ускоряет остановку 3D-инерции. Автоматическое переключение изображений каждые пять секунд продолжает работать.

### 7. Внешний шрифт зависит от сети

Inter загружается с Google Fonts. При отсутствии сети сайт остаётся читаемым благодаря Arial, но размеры строк могут немного измениться.

### 8. `:has(...)` требует современного браузера

Селектор `html:has(body....)` используется для скрытия горизонтальной прокрутки и scrollbar на нескольких проектных страницах. В современных браузерах он поддерживается, но в очень старых версиях эти правила будут пропущены.

## 17. Безопасный порядок будущей работы со стилями

1. Определить одну страницу и один конкретный элемент.
2. Найти класс элемента в HTML.
3. Найти этот класс в `css/styles.css`.
4. Проверить, нет ли второго правила с тем же классом ниже по файлу.
5. Проверить все медиазапросы для этого класса.
6. Проверить, не добавляет ли JavaScript класс или `transform`.
7. После изменения посмотреть desktop, промежуточную ширину и mobile.
8. Для общих правил дополнительно открыть несколько других страниц.

Контрольная точка перед будущими изменениями уже сохранена в Git-коммите `13ed934` (`Checkpoint before style updates`).
