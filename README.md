# Portfolio

Personal portfolio site.

## Локальный запуск

1. Дважды нажмите на файл `start-site.command` в корне проекта.
2. Оставьте открывшееся окно Терминала работающим. Страница с 3D-книгой откроется в браузере автоматически.
3. Чтобы остановить сайт, вернитесь в Терминал и нажмите `Control + C`.

Если macOS не запускает файл двойным нажатием, нажмите на него правой кнопкой мыши и выберите «Открыть».

Адрес страницы с книгой: <http://localhost:8000/projects/zavodnoi-apelsin/index.html>

## Компонент 3D_COMP

`3D_COMP` — переиспользуемый контейнер с интерактивной 3D-книгой. Он включает модель, текущую яркость, вращение мышью и пальцем, клавиатурное управление и инерцию.

Чтобы использовать компонент в другом месте, добавьте контейнер с атрибутом `data-component="3D_COMP"`, классом `orange-book-viewer` и резервным изображением:

```html
<div class="orange-book-viewer" data-component="3D_COMP" tabindex="0">
  <img class="orange-book-viewer__fallback" src="путь/к/изображению.png" alt="Обложка книги">
</div>
```

На странице также должен быть один общий модуль:

```html
<script type="module" src="путь/к/js/orange-book-3d.js"></script>
```

Можно добавить несколько `3D_COMP` на одну страницу. Каждый экземпляр вращается независимо, а модель и настройки берутся из общих файлов `js/orange-book-prototype.js` и `js/orange-book-3d.js`, поэтому изменения применяются ко всем копиям сразу. Компоненты загружаются только перед появлением на экране.
