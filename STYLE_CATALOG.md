## 1. Как читать каталог

### Устройства

В этом проекте нет единого определения «планшета». Используются такие диапазоны:

| Название в каталоге | Фактическое условие |
|---|---|
| Desktop | обычно 1400 px и шире |
| Планшет / узкий desktop | для фиксированных проектов: 900–1399 px |
| Телефон | для фиксированных проектов: до 899 px; для главной, каталога и ширм: до 699 px |
| Очень узкий телефон | до 370 px |

На ширине ровно 700–899 px главная уже использует desktop-вариант сетки, а фиксированные проектные страницы всё ещё используют mobile-композицию.

### Что означает «итог зависит от браузера»

Точное число невозможно назвать статически, когда используется:

- `%`, `vw`, `vh` — значение зависит от размера окна;
- `clamp()` — браузер выбирает значение между минимумом и максимумом;
- `calc()` — значение вычисляется из ширины окна или родителя;
- `ch`, `rem` — значение зависит от шрифта или корневого размера;
- CSS-переменная, которую меняет JavaScript;
- естественные пропорции картинки;
- WebGL-canvas, который рисуется JavaScript.

### Краткий словарь свойств

Этот словарь используется в таблицах с повторяющимися элементами.

| Свойство | Простое объяснение | Что будет при изменении |
|---|---|---|
| `width`, `height` | ширина и высота коробки элемента | элемент станет больше или меньше; у фиксированных сцен может пересечь соседей |
| `max-width` | верхний предел ширины | увеличение разрешит элементу стать шире, уменьшение раньше ограничит его |
| `margin` | внешний отступ от соседей | меняет расстояние между блоками |
| `padding` | внутренний отступ от края блока | содержимое приблизится к краю или отдалится от него |
| `gap` | промежуток между элементами grid/flex | карточки или колонки разойдутся либо сблизятся |
| `top`, `left`, `right` | координаты абсолютно расположенного элемента | элемент сдвинется по сцене; поток страницы не перестроится |
| `position: absolute` | элемент вынут из обычного потока и поставлен по координатам | без него `top/left` перестанут работать как координаты сцены |
| `display: grid` | раскладывает дочерние элементы по сетке | изменение колонок перестроит композицию |
| `display: flex` | раскладывает дочерние элементы по оси | изменение направления или выравнивания переставит элементы |
| `object-fit: fill` | растягивает картинку точно в рамку | изображение может изменить пропорции |
| `object-fit: cover` | заполняет рамку с обрезкой краёв | больше рамка — видно больше или крупнее; пропорции сохраняются |
| `object-fit: contain` | показывает картинку целиком внутри рамки | могут появиться свободные поля |
| `overflow: hidden` | обрезает всё, что выступает за рамку | при `visible` выступающие части станут видны |
| `transform` | визуально сдвигает, поворачивает или масштабирует | меняет видимое положение, не занимая новое место в потоке |
| `font-size` | размер букв | меняет размер текста и переносы строк |
| `font-weight` | толщина букв | большее число делает текст визуально жирнее |
| `line-height` | высота строки | меняет вертикальное расстояние между строками |
| `letter-spacing` | расстояние между буквами | текст станет плотнее или разреженнее |
| `color`, `background` | цвет текста и фона | изменяет контраст и общую цветовую подачу |
| `aspect-ratio` | пропорция ширины к высоте | при изменении рамка станет выше или ниже при той же ширине |
| `z-index` | порядок наложения слоёв | большее значение поднимает элемент поверх других |
| `transition` | плавность изменения свойства | длительность меняет скорость; удаление делает смену мгновенной |

## 2. Общая визуальная основа

### 2.1. Шрифт сайта

| Поле | Значение |
|---|---|
| Страницы | все страницы, подключающие общий CSS |
| Источник | `css/styles.css:1`, `css/styles.css:6` |
| Селектор | `@import ...Inter...`, `body` |
| Свойства | `font: 400 16px/1.18 Inter, Arial, sans-serif`; `-webkit-font-smoothing: antialiased` |
| Объяснение | Основной текст имеет размер 16 px, толщину 400 и высоту строки 1.18. Сначала используется Inter, затем Arial. Сглаживание делает буквы на WebKit/macOS визуально тоньше и ровнее. |
| Если изменить | Размер изменит весь наследующий текст и переносы строк; вес изменит плотность; line-height — вертикальный ритм; смена шрифта изменит ширину символов и может нарушить фиксированные макеты. |
| Адаптивность | База одинакова. Отдельные страницы ниже переопределяют line-height и размеры заголовков. |
| Каскад | `body:not(.portfolio-page)` на строке 106 меняет `line-height` на `1.45`. Специализированные страницы повторно задают шрифт и параметры своим текстовым элементам. |

### 2.2. Цвета страницы и ссылок

| Поле | Значение |
|---|---|
| Страницы | весь сайт с общим CSS |
| Источник | `css/styles.css:3`, `css/styles.css:6–8` |
| Селектор | `:root`, `body`, `a`, `a:hover ...` |
| Свойства | `--ink: #141414`; `--muted: #676767`; `background: #fff`; `color: var(--ink)`; ссылки: `color: inherit`, `text-decoration: none`; hover: `text-decoration: underline`, `text-underline-offset: .14em` |
| Объяснение | Страница белая, основной текст почти чёрный. Ссылки выглядят как окружающий текст, пока курсор не активирует заданное подчёркивание. `.14em` отодвигает линию от букв пропорционально размеру текста. |
| Если изменить | Цвета изменятся на всех наследующих страницах. Удаление `text-decoration: none` вернёт стандартное подчёркивание всех ссылок. |
| Адаптивность | Не меняется по ширине. Hover обычно актуален для мыши, а на сенсорном экране может не проявляться. |
| Каскад | Специализированные страницы задают `color: #111`, почти тот же цвет. Email в CV переопределён синим. |

### 2.3. Модель размеров и картинки по умолчанию

| Поле | Значение |
|---|---|
| Страницы | весь сайт с общим CSS |
| Источник | `css/styles.css:4`, `css/styles.css:9–10` |
| Селектор | `*`, `img`, `.portfolio-page, .portfolio-page *` |
| Свойства | `box-sizing: border-box`; картинки: `display: block; width: 100%; height: auto`; на главной `border-radius: 0 !important` |
| Объяснение | Размер элемента включает padding и border. Картинка занимает ширину родителя и сохраняет пропорции. На главной любые скругления принудительно обнулены. |
| Если изменить | `content-box` усложнит расчёт ширин. Фиксированная высота картинки может исказить её без `object-fit`. Удаление `!important` разрешит локальным скруглениям работать. |
| Адаптивность | `width: 100%` автоматически следует за шириной родителя. |
| Каскад | Страничные правила часто переопределяют `height`, `width` и `object-fit`; `border-radius: 0 !important` на главной сильнее обычных правил. |

### 2.4. Переменные, от которых зависят видимые размеры

Источник глобальных переменных: `css/styles.css:3`.

| Переменная | Значение | Видимые элементы | Что произойдёт при изменении |
|---|---|---|---|
| `--ink` | `#141414` | основной текст, активная навигация | изменит основной цвет везде, где нет локального `#111` |
| `--muted` | `#676767` | ссылки «Назад» обычных страниц, год, footer | изменит цвет второстепенного текста |
| `--content` | `980px`; от 700 px переопределён на `900px` строкой 85 | ширина шапки и main главной | большее значение расширит главную до нового максимума |
| `--tile-gap` | `clamp(10px,2.5vw,20px)` | карточки, коллажи, постеры | меняет промежутки плавно; итог зависит от viewport |
| `--segment-gap` | `clamp(2px,.5vw,4px)` | щели между частями hover-коллажей | большее значение сильнее разделит сегменты |
| `--poster-column-width` | `clamp(100px,27vw,190px)` | левая колонка 365+ Posters | меняет ширину постеров и оставшееся место интерьерной карточке |
| `--shift-x`, `--shift-y` | начально `0px`; runtime из JS | картинки книг и визуальной системы | двигают картинку внутри обрезанной рамки |
| `--posters-height` | fallback `583px`, затем измерение JS | высота колонки постеров | определяет, сколько постеров видно без внутренней прокрутки |
| `--art-x`, `--art-y` | индивидуальны для трёх карточек | изображения каталога интерьерных проектов | точечно корректируют композиционное положение |

### 15.3. Интерактивная картинка ширм

Источник: `js/screens-scrub.js:1–42`.

JavaScript делит ширину `.screens-scrub` на число кадров и меняет `img.src` по горизонтальной позиции указателя. Стрелки клавиатуры переключают соседний кадр. CSS-свойства размера и `object-fit:contain` не меняются; меняется только содержимое картинки. Поэтому итоговый вид конкретного кадра невозможно определить без текущего положения указателя.

### 15.4. Визуальные параметры 3D-книги

Основной preset: `js/orange-book-3d.js:17–31`. Реализация: `js/orange-book-prototype.js:16–238`.

Освещение по умолчанию создаётся на строках 148–184, но preset заменяет интенсивности трёх направленных источников. Прозрачные viewer персональной выставки не получают плоскость тени (`if (!transparent)`), а обычная страница книги получает её с итоговой opacity `0` из preset.

Размер canvas: `js/orange-book-prototype.js:752–760`. При ширине viewer менее 640 px pixel ratio ограничен `1.5`, иначе `2`; это компромисс качества и производительности. Фактическое число также ограничено `window.devicePixelRatio`.

Инерция: строки 729–739. Обычный damping `0.928`, при `prefers-reduced-motion` — `0.7`, поэтому книга быстрее останавливается. Полностью движение не отключается.

| Края | `color:0xd9d2c6; roughness:.86; metalness:0; bumpScale:.024` | тёплый картонный край, матовый и фактурный |
| Печать | `color:white; roughness:.76; metalness:0; sheen:.025; sheenRoughness:.94; clearcoat:.006; bumpScale:.009` | почти матовая бумажная поверхность с очень слабым блеском |
| Экспозиция | `.94` | делает 3D-сцену немного темнее нейтральной |
| Pair layout | позиции `[-.52,-.35,-.06]` и `[.38,.35,.1]`, повороты Z `-.25` и `.38`, scale `.82` | две листовки перекрываются по диагонали; изменение чисел меняет композицию |

Как и книга, листовки меняют pixel ratio и камеру при ширине viewer меньше 640 px. Инерция имеет damping `.89`, при reduced motion `.65`, поэтому быстро затухает. Точное положение после перетаскивания статически определить невозможно.

### 15.6. Инспектор типографики

Источник JS: `js/style-inspector.js:1–18`; CSS: `css/styles.css:1157–1184`.

При параметре `?styles=1` body получает `.style-inspection`. Заголовки и выбранные абзацы получают `position:relative`, пунктирный outline `1px`, offset `5px`; цвета: h1 `#d60000`, h2 `#078a32`, h3 `#075ad8`, абзацы `#5d32a8`. Псевдоэлемент подписи имеет абсолютную позицию, `z-index:20`, отступы `.2em .45em`, белый текст, фон текущего диагностического цвета и шрифт `500 11px/1.1 Inter`. Это временно перекрывает реальные цвета текста, поэтому режим нельзя использовать для оценки цветовой палитры страницы.

## 16. Карта переопределений

### 16.1. Как браузер выбирает правило

Если несколько правил задают одно свойство, браузер учитывает:

1. `!important`;
2. точность селектора — ID обычно сильнее класса, класс сильнее тега;
3. при одинаковой точности — правило, записанное ниже;
4. inline-стиль из JavaScript обычно сильнее обычного CSS.

### 16.3. Значения, которые нельзя точно определить статически

| Значение | Почему |
|---|---|
| Фактический Inter или Arial | зависит от загрузки Google Fonts и доступности шрифтов |
| Размеры через `clamp`, `vw`, `vh`, `%`, `calc` | зависят от viewport и размера родителя |
| Высота колонки постеров | измеряется JavaScript по `.doors-column` |
| Положение картинок в hover-коллажах | зависит от координат указателя |
| Положение панорамной картинки | зависит от размеров и последнего жеста |
| Текущий кадр переключателя или ширм | зависит от таймера, свайпа, указателя или клавиатуры |
| Размер WebGL-буфера | зависит от CSS-размера viewer и `devicePixelRatio` |
| Ракурс 3D-объекта | меняется пользователем и инерцией |
| Точный вид материалов WebGL | зависит от GPU, браузера, цветового профиля, текстур и tone mapping |
| Переносы текста с `text-wrap:balance` | рассчитываются браузером по доступной ширине и метрикам загруженного шрифта |

Для проверки таких значений нужен конкретный размер окна и вкладка Computed в инструментах разработчика браузера.
